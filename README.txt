PATRIOT – Sales Process Concept v0.4

Cara pakai:
1. Extract seluruh folder ZIP.
2. Buka index.html di Chrome atau Edge.
3. Gunakan tab Overview / Lead Baru / Customer Existing / Sales Target untuk highlight jalur.
4. Klik object yang memiliki icon ↗ untuk membuka drawer screen.
5. Klik tombol screen di drawer untuk membuka HTML mockup lengkap pada tab baru.

Konsep utama:
- Diagram menjadi tampilan utama.
- Tidak ada supporting screenshot besar di bawah.
- Customer Existing langsung masuk ke Visit & Follow-up pada master journey.
- Commercial Result menampilkan dua jalur: melalui Sales Quotation atau langsung ke Sales Order.
- Sales Target tetap berada di bagian akhir sebagai planning/performance layer.
